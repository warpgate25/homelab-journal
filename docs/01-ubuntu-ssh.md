## ⚠️ Дополнение: Инцидент с SSH Hardening & Troubleshooting

В процессе настройки жесткого Hardening (отключение паролей, работа строго по ключам Ed25519) возникла проблема с доступом через PowerShell.

### Причина и хронология:
1. **Смена IP:** Виртуальная машина получила новый IP `192.168.1.202` по DHCP. В файле `known_hosts` на Windows уже лежал старый отпечаток для этого IP, из-за чего SSH выдавал ошибку безопасности. Проблема решена через:
   ```powershell
   ssh-keygen -R 192.168.1.202

   Конфликт sshd_config.d: В Ubuntu Server настройки из /etc/ssh/sshd_config.d/*.conf перекрывали базовый sshd_config. Команды sed не включали пароль назад, пока не была очищена директория доп. конфигов:

Bash
sudo rm -rf /etc/ssh/sshd_config.d/*
Итоговое решение:
Для удобства работы в учебной лаборатории парольная аутентификация была временно возвращена (PasswordAuthentication yes), а конфиг приведен к рабочему виду.
