# 🛠️ SOC & SysAdmin Command Cheat Sheet

Памятка по основным командам Linux, Windows PowerShell и языка LogQL, использованным в ходе прохождения практического курса.

---

## 🐧 Linux (Ubuntu Server) & Bash

### 1. Навигация и работа с файлами
* `cd <dir>` — перейти в указанную директорию[cite: 1].
* `cd ~` — перейти в домашнюю директорию пользователя[cite: 1].
* `ls -la` — показать полный список файлов и папок (включая скрытые и права доступа)[cite: 1].
* `pwd` — показать текущий рабочий путь[cite: 1].
* `mkdir -p <dir>` — создать папку (включая вложенные директории)[cite: 1].
* `nano <file>` — открыть текстовый редактор Nano[cite: 1].
* `cat <file>` — вывести полное содержимое файла в консоль[cite: 1].

### 2. Быстрые горячие клавиши в Nano
* `Ctrl + O` ➔ `Enter` — сохранить изменения в файле[cite: 1].
* `Ctrl + X` — выйти из редактора[cite: 1].
* `Ctrl + K` — вырезать (удалить) текущую строку[cite: 1].
* `> file.txt` — быстро очистить содержимое файла до нуля (выполняется в Bash)[cite: 1].

### 3. Анализ логов и работа с текстом (Log Analysis)
* `journalctl -u <service>` — просмотр системных логов конкретной службы (например, `ssh`)[cite: 1].
* `grep "<text>" <file>` — поиск строки или шаблона в файле[cite: 1].
* `grep -i` — поиск без учета регистра букв[cite: 1].
* `awk '{print $1}'` — извлечение конкретной колонки (столбца) из текста[cite: 1].
* `sort` — сортировка строк по алфавиту/значению[cite: 1].
* `uniq -c` — группировка повторяющихся строк с подсчетом их количества[cite: 1].
* `wc -l` — посчитать точное количество строк в файле или потоке[cite: 1].

### 4. Сеть и диагностика
* `ip a` — посмотреть IP-адреса и сетевые интерфейсы сервера[cite: 1].
* `ping <ip>` — проверка сетевой доступности узла[cite: 1].
* `tcpdump -i <interface>` — перехват и анализ сетевых пакетов в реальном времени[cite: 1].

### 5. Управление Docker & Docker Compose
* `docker ps` — список всех запущенных контейнеров[cite: 1].
* `docker ps -a` — список всех контейнеров (включая остановленные)[cite: 1].
* `docker logs <container_name>` — просмотреть логи конкретного контейнера[cite: 1].
* `docker compose up -d` — запустить стек сервисов из `docker-compose.yml` в фоновом режиме[cite: 1].
* `docker compose down` — остановить и удалить все контейнеры стека[cite: 1].
* `docker compose restart <service>` — перезапустить конкретный сервис (например, `promtail`)[cite: 1].

### 6. Работа с Git & GitHub
* `git status` — проверить статус изменений в репозитории[cite: 1].
* `git add .` (или `git add docs/`) — подготовить файлы к коммиту[cite: 1].
* `git commit -m "<message>"` — зафиксировать изменения с комментарием[cite: 1].
* `git push` — отправить коммиты в удаленный репозиторий GitHub[cite: 1].

## 🪟 Windows (PowerShell & CLI)

### 1. Подключение и сеть
* `ssh user@<ip>` — подключение к Linux-серверу по протоколу SSH[cite: 1].
* `curl "http://<ip>/..."` — отправка HTTP-запроса к веб-серверу[cite: 1].
* `ipconfig` — посмотреть сетевые настройки и IP-адрес ПК[cite: 1].

### 2. Симуляция атак и аудит
* `net use \\<ip> /user:<domain>\<user> <password>` — попытка подключения к сетевому ресурсу (для генерации `Event ID 4625`)[cite: 1].
* `eventvwr.msc` — запуск графического журнала событий **Windows Event Viewer**[cite: 1].

## 📊 Grafana Loki (LogQL)

* `{job="varlogs"}` — вывод общего потока логов из системы[cite: 1].
* `{job="varlogs"} |= "Failed password"` — фильтрация логов с поиском попыток подбора паролей SSH[cite: 1].
* `{job="varlogs"} |= "id=1"` — поиск веб-запросов и подозрительных SQLi-параметров[cite: 1].
